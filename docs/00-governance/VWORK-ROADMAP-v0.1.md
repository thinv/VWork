# VWork – Documentation & Engineering Roadmap v0.1

## Wave 0 – Product Baseline & Compliance
Repository, scope, documentation standard, compliance baseline.

## Wave 1 – Proposal
Master Proposal, Technical Narrative, Scope of Work, deployment/commercial model.

## Wave 2 – Business Requirements
BRD, business processes, actors.

## Wave 3 – Detailed Requirements
Use Cases, Business Rules, FR/NFR, SRS.

## Wave 4 – Architecture
System/Application/Data/AI/Security/Integration/Deployment Architecture.

## Wave 5 – Data & API
Domain model, dictionary, ERD, API catalog, OpenAPI, event/integration contracts.

## Wave 6 – UX
Web Screen Catalog, Mobile Screen Catalog, wireframes, design system.

## Wave 7 – AI Detailed Design
RAG, AI Gateway, prompts, providers, evaluation, guardrails.

## Wave 8 – Security Detailed Design
IAM, RBAC/data scope, threat model, audit, security testing.

## Wave 9 – Engineering Foundation
Monorepo/toolchain, environments, CI/CD, observability, migrations.

## Wave 10 – Core Implementation
Theo vertical slices có traceability đầy đủ.

## Wave 11 – Qualification
Integration, performance, security, AI evaluation, UAT.

## Wave 12 – Deployment & Acceptance
Installation, training, handover, SLA, nghiệm thu.

## Exit gate chung
Không đóng Wave khi deliverables bắt buộc chưa APPROVED hoặc traceability còn gap blocking.
