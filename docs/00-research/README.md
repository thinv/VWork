## Quy tắc sử dụng
- BRD phải lấy Capability Map và Product Boundary làm baseline.
- Feature mới phải được phân loại Adopt / Improve / Defer / Reject.
- Yêu cầu ngoài Core v1 phải đi qua Change Request hoặc được đưa vào Extension/Future.
- Benchmark chỉ dùng để học pattern nghiệp vụ công khai; không sao chép UI, thương hiệu, mã nguồn hoặc nội dung độc quyền.
