## Quy tắc traceability

Mọi yêu cầu phải có ID và truy vết theo chuỗi:

Research/Capability → Business Process → BRD Requirement → Actor → Use Case → Business Rule → FR/NFR → SRS → Screen/API/Data → Code → Test → UAT → Release.

ID đã cấp trong BRD và Use Case Catalog phải được giữ ổn định để không phá traceability.
